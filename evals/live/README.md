# Live transcripts

Real conversations with the deployed ElevenLabs agent, fetched from the running
API after a browser session and committed exactly as ElevenLabs stored them.
Nothing here is written or edited by hand.

Every live transcript is kept, including accidental and badly-behaved ones. They
are run through the same checks as the scenario library by
`tests/test_live_transcripts.py`, and what those checks make of them is pinned,
so a change to the rules shows its effect on real speech and not only on scripts.
